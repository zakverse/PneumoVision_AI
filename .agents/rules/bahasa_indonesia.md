# Aturan Bahasa Proyek PneumoVision_AI

Mulai sekarang, seluruh dokumentasi dan konten proyek PneumoVision_AI wajib menggunakan Bahasa Indonesia.

## Prinsip Penggunaan Bahasa:
1. **Dokumentasi & Markdown**:
   - `README.md` dan sub-README wajib menggunakan Bahasa Indonesia.
   - Semua Markdown cells di Jupyter Notebook (`notebooks/*.ipynb`) wajib menggunakan Bahasa Indonesia.
   - Judul, subjudul, penjelasan konsep, insight, dan kesimpulan menggunakan Bahasa Indonesia.
2. **Komentar & Teks Output**:
   - Komentar kode menggunakan Bahasa Indonesia jika diperlukan.
   - Output teks yang dicetak/dihasilkan oleh notebook atau script analisis menggunakan Bahasa Indonesia.
3. **Istilah Teknis (Tetap Bahasa Inggris)**:
   - Tetap gunakan istilah teknis standar dalam Bahasa Inggris jika merupakan nama teknis, library, arsitektur model, metrik, atau konsep machine learning.
   - Contoh: *CNN, Transfer Learning, EfficientNet, ResNet, DenseNet, PyTorch, Accuracy, Precision, Recall, F1-Score, ROC-AUC, Grad-CAM, Epoch, Batch Size, Learning Rate, Overfitting, Data Leakage, Class Imbalance, False Negative, False Positive, Loss*.
   - Jangan menerjemahkan nama library, nama arsitektur, nama fungsi, atau metrik evaluasi.
4. **Tone & Gaya Penulisan**:
   - Jelas, santai tetapi profesional.
   - Mudah dipahami oleh mahasiswa dan praktisi pemula.
   - Tidak terlalu kaku/akademis yang membingungkan.
   - Selalu menjelaskan alasan (*the "why"*) di balik setiap langkah analisis dan pemodelan.
5. **Keselamatan Medis**:
   - Wajib selalu menyertakan disclaimer medis bahwa proyek ini untuk tujuan edukasi dan riset, bukan alat diagnosis medis klinis.
